# Кабінет психолога

Односторінковий вебдодаток для психолога-ФОП: облік надходжень, податків і прибутку, плани лікування, рахунки та акти.

**Відкрити:** https://dujmovo4ka-ops.github.io/psy-cabinet/

## Можливості

- **Звіт по доходах** — таблиця P&L за 12 місяців і помісячне заповнення: надходження, витрати, виплати прибутку, залишок.
- **Податки** — єдиний податок і військовий збір у % від надходжень, ЄСВ у грн/міс; ставки можна змінити з будь-якого місяця.
  За замовчуванням: ЄП 5 %, ВЗ 1 %, ЄСВ 0 грн.
- **Імпорт банківської виписки** (.xls/.xlsx) з автоматичним розпізнаванням замовників.
- **Довідники** — замовники та договори, послуги, власні реквізити.
- **Документи** — рахунки та акти з друком у PDF.
- **План лікування** — калькулятор послуг на період.

## Дані

Усе зберігається лише у вашому браузері (localStorage) — нічого не передається на сервер.
Для резервної копії — кнопки «Експорт даних» / «Імпорт даних» (JSON) або «Автозбереження» у файл (Chrome/Edge).

Працює офлайн: можна просто завантажити `index.html` і відкрити у браузері.
